# 📊 Superstore Sales & Orders Dashboard
This Power BI project analyzes sales and orders data from a fictional Superstore to uncover insights across categories, products, customer segments, locations, and time.

## 🔍 Project Overview
The Superstore dataset was visualized using Power BI to assist stakeholders in understanding business performance and identifying areas for growth. The dashboards provide a comprehensive view of sales and order trends from 2015 to 2018 across key dimensions.

## 📁 Dashboards Included
### 1. Sales Analysis
* Total sales by product category (Office Supplies, Furniture, Technology)

* Top-selling individual products

* Temporal sales trends across years

* Filter by state and year

### 2. Orders Analysis
* Total orders by category and top products

* Monthly order trends over the 4-year period

* Filterable by state and year

### 3. Location Analysis
* Sales and orders by top-performing states (e.g., California, New York, Texas)

* Geographic filters for interactive exploration

* Year-over-year location performance comparison

### 4. Customer Analysis
* Top customers by sales and order volume

* Segment-wise performance (Consumer, Corporate, Home Office)

* Insights into customer behavior and high-value clients

## 🛠 Tools Used
* Power BI Desktop for data modeling, DAX measures, and dashboard creation

* [Superstore dataset](https://www.kaggle.com/datasets/rohitsahoo/sales-forecasting/data) (public sample dataset for data visualization)

## 🎯 Key Insights
* Technology was the leading category in terms of sales.

* California drove the highest sales and order volume.

* Sean Miller was the top-spending customer, while William Brown placed the most orders.

* Consumer segment accounted for the majority of sales and orders.

## 📌 How to Use
1. Open the Power BI dashboard file (.pbix) in Power BI Desktop.

2. Use the slicers and filters (State, Year, Segment) to explore the data interactively.

3. Identify trends and patterns to support data-driven decisions.
